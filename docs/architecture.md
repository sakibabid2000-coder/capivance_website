# CAPIVANCE Website Architecture

- `src/app` — routes and application entry points
- `src/components/navigation` — global header/footer
- `src/components/home` — homepage sections
- `src/components/ui` — small reusable UI primitives
- `src/data` — site navigation and content data
- `src/lib` — utilities and future integrations
- `src/types` — shared TypeScript types
- `public` — static assets
- `docs` — product and architecture documentation
