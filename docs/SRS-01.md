# SRS-01 — CAPIVANCE Corporate Website

This repository implements the SRS-01 corporate website foundation using Next.js App Router and TypeScript.

## Core sections
- About CAPIVANCE
- Learning
- Entrepreneurship
- Research
- Business Advisory
- Financial & Digital Solutions
- Knowledge Hub
- Contact

## Architecture
The homepage is composed from reusable components under `src/components/home`, while route pages live under `src/app`.
